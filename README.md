## About

RJX Patches is an independent, community-maintained patch collection for Android apps supported by [Morphe](https://morphe.software). The goal is to expand app coverage with useful, carefully documented patches and keep compatibility information visible.

**RJX Patches is an independent project and is not affiliated with or endorsed by Morphe.** Morphe is the patching platform; this repository provides a separate community patch source.

## Add the source

1. Install Morphe from its [official website](https://morphe.software).
2. Open the [RJX Patches source link](https://morphe.software/add-source?github=visionxstream99-mod/rjx-patches).
3. Review the available patches and select the ones you want.
4. Check the target app version and release notes before patching.

You can also add this repository manually in Morphe's patch-source manager:

`visionxstream99-mod/rjx-patches`

Patch compatibility is version-specific. Each patch should document its target package, supported app version(s), purpose, options, known limitations, and test status. A successful compile alone does not prove that a patch works correctly at runtime.

## Roadmap

- [ ] Audit existing community sources and avoid duplicating patches without a reason.
- [ ] Select a first target app and verify the exact version.
- [ ] Implement a small, focused patch with clear fingerprints and settings where appropriate.
- [ ] Build with the official Morphe patching toolchain.
- [ ] Test installation, runtime behavior, and interaction with other patches.
- [ ] Publish a versioned release with generated metadata and changelog.
- [ ] Expand the catalog based on compatibility and community requests.

## Request a patch or report a bug

Please search existing issues before opening a new one. Include:

- App name and package ID
- Exact app version and download source
- Morphe version and RJX release/channel
- Patch selected and its options
- Steps to reproduce and relevant logs
- Whether the issue occurs with only that patch enabled

Use the [issue tracker](https://github.com/visionxstream99-mod/rjx-patches/issues).

## Development

RJX follows the official [Morphe patch development documentation](https://github.com/MorpheApp/morphe-documentation) and the build/release structure supplied by the [Morphe Patches template](https://github.com/MorpheApp/morphe-patches-template).

- Develop on the `dev` branch.
- Use descriptive semantic commits such as `feat:`, `fix:`, and `chore:`.
- Keep release artifacts and generated catalog files managed by the template's release workflow.
- Record the target app version and test status for every patch.
- Never claim a patch is tested unless the relevant behavior was actually verified.

## Project scope

This repository focuses on app patches and modifications that can be documented, reviewed, and tested. Patches must not misrepresent compatibility or safety, and must respect the rights and security of users and developers. Issues involving paid entitlements, subscription checks, or licensing restrictions are not part of this project's supported scope.
